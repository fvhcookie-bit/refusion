# Чек-лист проверки спецификации на загрязнение

Редактор проходит его для **каждого** изменения в `spec/` перед выпуском. Автоматическая часть —
`python docs/process/check_spec.py`; она ловит очевидное, но не заменяет чтение глазами.

## A. Запрещено в `spec/` (возврат без обсуждения)
- [ ] Адреса памяти и кода оригинала (вида `0x1A2B3C`), смещения полей **структур в памяти** (`корабль + 0x...`).
      Смещения внутри **файлов** (`.TRK`, `GAME.BNI`, сохранение) — разрешены: это формат данных.
- [ ] Дизассемблер, псевдокод декомпилятора, фрагменты кода оригинала в любом виде, в том числе «пересказ построчно».
- [ ] Внутренние имена оригинала: функций, переменных, полей, классов, файлов исходников, отладочных меток —
      даже переведённые транслитом или слегка изменённые. Признаки: `_Q`, `g_`, `FUN_`, `DAT_`, `CamelCase_С_Подчёркиванием`,
      `.cpp`, имена полей вроде `fooBarBaz`.
- [ ] Строки, которые есть **только в исполняемом файле** (отладочные сообщения, имена enum'ов), — кроме текста, который
      игрок видит на экране, и имён из файлов данных.
- [ ] Названия и ссылки на закрытые материалы исследования: заметки, декомпилят, инструменты реверса, номера сохранений.
- [ ] Битовые значения внутренних флагов и масок памяти (биты в **файлах** — можно).

## B. Проверить по смыслу
- [ ] Правило описывает **поведение** (вход → наблюдаемый результат), а не устройство кода. Порядок шагов указан, только
      если он влияет на результат, и это сказано.
- [ ] Новые термины — из данных игры, с экрана или описательные; есть в глоссарии (`spec/00_glossary.md`).
- [ ] У правила есть ID и отметка `[✓]` / `[код]` / `[?]`; у `[✓]` в скобках сказано, чем подтверждено (без адресов).
- [ ] Для каждого нового ID есть строка в закрытом журнале трассировки (не публикуется).
- [ ] Константы и таблицы — минимальные, нужные для результата. Большие таблицы из исполняемого файла не переносятся
      целиком без необходимости; если без них нельзя — помечено, откуда «механически» они берутся (например, «из файла данных»).
- [ ] Нет «подсказок» вида «в оригинале это сделано так-то», «оригинальная функция …».
- [ ] Неизвестное не замазано догадкой: либо `[?]`, либо пункт в `08_open_questions.md`.

## C. Выпуск
- [ ] `check_spec.py` — без замечаний.
- [ ] Запись в `spec/CHANGELOG.md`: номер выпуска, изменённые ID, кто проверил, дата.
- [ ] Ответы на вопросы `spec/QUESTIONS.md` ссылаются на ID правил.
- [ ] Тег `spec-rN` поставлен, архив собран командой из `process/README.md`.
