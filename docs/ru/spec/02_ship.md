## SHIP-4. Живые параметры [✓]
На время гонки у каждого корабля — **своя копия** параметров. Её создают при подготовке гонки (FLOW-4), а затем
меняют апгрейды (SHIP-5), уничтожение (SHIP-9), лава (PHY-21), AG Stinger (WPN-14), режим Zone (RACE-19).
Физика читает только копию. Исходная `maxspeed` после апгрейдов запоминается отдельно и в гонке не меняется.

## SHIP-5. Апгрейды [✓]
Шесть групп с уровнями 1–6. Уровень **заменяет** базовое значение параметра в живой копии:

| группа | ключ уровня | что заменяет |
|---|---|---|
| TOPSPEED | `TOPSPEED_maxspeed_UPGn`, `TOPSPEED_gravityflying_UPGn` | `maxspeed`, `gravityflying` |
| THRUST | `THRUST_accelforcemultiplier_UPGn` | `accelforcemultiplier` |
| BRAKING | `BRAKING_brakeforce_UPGn`, `BRAKING_brakefullinc_UPGn` | `brakeforce`, `brakefullinc` |
| STABILITY | `STABILITY_turninc_UPGn`, `STABILITY_turndamping_UPGn`, `STABILITY_braketurndamping_UPGn` | `turninc`, `turndamping`, `braketurndamping` |
| WEAPON | `WEAPON_weaponpower_UPGn` | `weapon_standard` |
| SHIELD | `SHIELD_shieldpower_UPGn` | `shield_standard` |

Значение 0 в INI означает «уровня нет». Пример — TC-5. ИИ-соперники тоже получают апгрейды
(у них `weapon_standard` от 1.0 до 2.1 при 1.1 у игрока); как выбираются их уровни — SHIP-16.
Уровни игрока покупаются за кредиты на экране апгрейдов.

**Экран апгрейдов** [✓ наблюдение игрока, PAL: Xios lead, Natasha Belmondo; значения сверены с `SHIPS.INI`]:
- для каждой группы — текущее значение, следующий уровень и цена; цена уровня n — `cost_<ГРУППА>_UPGn`
  (Xios lead: TOPSPEED 227 790, THRUST 179 865, BRAKING 123 975, STABILITY 138 375, WEAPON 217 080, SHIELD 168 458
  за первый уровень); покупка — с подтверждением «accept upgrade yes / no», кредиты уменьшаются ровно на цену;
- что показывается вместо внутренних величин:
  | строка | значение на экране | пример (база → 1-й уровень) |
  |---|---|---|
  | top speed, kph | `maxspeed` | 1114 → 1189 |
  | thrust, gfu | `accelforcemultiplier × 1100` | 7865 → 8690 → 9515 |
  | brake force, gfu | `brakeforce / 4` | 6875 → 7625 |
  | lateral stability, % | `turndamping / 2`, дробь отброшена до десятых | 34.3 → 35.8 |
  | weapon power, × | `weapon_standard` | 2.1 → 2.5 |
  | shield power, qsu | `shield_standard` | 71 → 75 |
  | mass, kg | 1177 у этого корабля; `mass` в `SHIPS.INI` у всех 2500 — откуда число, OQ-13 | — |
- «N % upgrade» — это доля прокачки `p` из SHIP-14 (у Xios lead 33 уровня: 1 уровень — 3 %, 2 — 6 %). Число делений в полосе группы = числу её уровней у этого корабля (у Xios lead — 5 или 6; у других кораблей в группе
  бывает и 3, см. пример в SHIP-14; всего уровней у кораблей 22…36),
  купленные — жёлтые;
- выбранная строка мигает: её полоса целиком вспыхивает жёлтым, поэтому на снимке полоса может выглядеть полной.
  игроку мигание показалось слишком частым — так ли задумано, не проверено [?];
- купленные уровни можно откатить: при откате уровня его цена возвращается **полностью** [✓ наблюдение игрока, PAL] — поэтому
  прокачку можно свободно переносить на другой корабль, например посреди лиги.

## SHIP-6. Щит [✓]
- Начальное значение = `shield_standard` (после апгрейда). Корабль **уничтожен**, когда после удара щит становится
  **меньше 0.9** — тогда он обнуляется (SHIP-9) [код; ✓ запись: щит 1.16 → удар → 0, уничтожен]. На экране щит
  показывается без дробной части (2.7 → «02»), поэтому при «00» корабль ещё может быть жив (щит 0.9…1.0).
- Касание стены отнимает около 1 единицы, сильный удар — 2–5. [✓ дуэль: щит 9, по 1 за касание; формула — OQ-6]
- Урон оружия — WPN-9.

## SHIP-7. Повреждения узлов [код; ✓ записи лиги PAL и US, многочасовые игровые наблюдения игрока]
Кроме щита у корабля есть повреждения узлов: двигатель, нос, стабилизаторы, аэротормоза (каждое 0…1). По наблюдениям игрока, первым повреждается элемент непосредственно в месте удара; после его полного разрушения урон переходит к соседним элементам. Повторными ударами по одному участку можно разрушить все элементы этой области. Элементы одного типа корабля у игрока и ботов могут разрушаться в разной последовательности. [наблюдение игрока; точные сравнительные замеры не проводились] Как урон делится по узлам — SHIP-15 (по группам корпуса у места удара).
Снижение урона при ударе зависит от расстояния до ближайшей неповреждённой группы: дальние группы получают меньше, а слишком удалённая группа может не получить урон. [код; согласуется с записью касаний]
За многочасовые игровые сессии связи между повреждением носа и применением оружия не наблюдалось. После разрушения носовой части оружие можно сразу подобрать и применить. Влияния повреждений других частей корпуса на применение оружия, силу, скорость снаряда, дальность или время до повторного выстрела не наблюдалось. [✓ наблюдение игрока, PAL; точные сравнительные замеры не проводились]
У носа визуальное разрушение может происходить быстрее двигателя или стабилизаторов, если корабль преимущественно получает урон в нос. Разрушение зависит от места попаданий, а после полного разрушения элемента урон переходит на соседние элементы. [наблюдение игрока]

**Штрафы.** Каждый кадр параметры узла пересчитываются от исходных (с апгрейдами):
`параметр = исходный × (1 − повреждение_узла × (1 − k))`, где `k` — значение `mdamage_<узел>_<параметр>` корабля
(`SHIPS.INI`; при `k` < 1 параметр падает, при `k` > 1 растёт). Повреждение 0 — параметр как у целого корабля,
повреждение 1 — `исходный × k`. Что ухудшает каждый узел:
| узел | параметры | пример: корабль игрока в записях, при полном повреждении |
|---|---|---|
| двигатель | тяга, высшая скорость | обе ×0.9 |
| нос | сила и предельный угол тангажа | ×0.6 |
| стабилизаторы | сила и предельный угол поворота, сила и предельный угол крена, демпфирование поворота, нарастание поворота | поворот ×0.6, крен ×0.8, нарастание ×1.4 |
| аэротормоза | сила торможения, нарастание торможения, крен/тангаж и поворот от тормозов | сила ×0.5 |
У разных кораблей `k` разные (например, тяга 0.6…0.9, поворот 0.6…0.8). Формула штрафов в обеих версиях игры одна.

**Прочность корпуса.** Четыре основные зоны корпуса имеют индивидуальные доли прочности; в данных каждой модели эти доли в сумме составляют 100 %. Более высокая доля соответствует большей стойкости зоны к накоплению повреждений. Общая ёмкость щита задаётся отдельно; точная связь долей с числом попаданий не установлена. [код; данные PAL; поведением не проверено]

**Ремонт.** На пит-лейне с подзарядкой (PHY-24) повреждения убывают одновременно с ростом щита, а параметры
возвращаются вместе с ними. Скорость ремонта — 0.7 повреждения в секунду (PAL), то есть из полностью разбитого
состояния ≈1.4 с [код; ✓ записи лиги PAL: 1.0 → 0 за 1.44 с дважды]. В US — в 1.2 раза быстрее, как другие величины
«за подшаг» (GEN-7): 1.0 → 0 за 1.20 с [✓ записи лиги US, дважды]. (Прежние «1.9 с» — ошибка подсчёта: в них вошёл
хвост подзарядки щита после конца ремонта.) Видимые повреждения корпуса на пит-лейне тоже исчезают [✓ наблюдение игрока, PAL]: деталь узла снова выглядит целой,
только когда узел починен **полностью**. Все узлы чинятся одновременно и с одной скоростью, поэтому раньше «целеют»
менее разбитые: в записи стабилизаторы (0.65) — через ~0.9 с подзарядки, нос (1.0) — через ~1.3–1.4 с, двигатели — по
тому, насколько были разбиты сами [✓ запись]; фонарь и кабина (у них нет узла) — **сразу** при въезде на подзарядку [✓ запись, три заезда на
пит-лейн]. Пока узел чинится, его повреждение поровну распределено между его деталями.
Без пит-лейна повреждения только копятся: в Time Trial (пит-лейн там включён, но игрок в него не заезжал) корабль
разбился о стены до уничтожения на 10-м круге Mandrashee 2R [✓ наблюдение игрока, PAL].

Наблюдение (тот же заезд: только стены, без оружия) [✓]: повреждения узлов от стен **копятся** — первым до
предела доходит нос (к 2-му кругу), затем стабилизаторы, двигатель (к 6–7-му), аэротормоза (к 9–10-му).
Когда двигатель повреждён полностью, разгон в диапазоне 700–1100 км/ч падает примерно на треть (~150 → ~90–115 км/ч
за секунду), высшая скорость на прямых ниже на ~10–15 %, боковое скольжение растёт на ~10 %. Игроку показалось,
что повреждения влияют на управляемость, — наблюдение это подтверждает.

## SHIP-9. Уничтожение [✓ покадровые наблюдения]
1. Щит = 0 → корабль **уничтожен**: каждый кадр максимальная скорость (`maxspeed`) умножается на 0.985, но не опускается
   ниже 50 (из ~1450 минимум достигается примерно за 4.5 с, TC-7); оба аэротормоза принудительно зажаты.
2. Промежуточные стадии через +1.2, +2.4 и +4.4 с от уничтожения (что меняется кроме эффектов — OQ-7).
3. Через **7.2 с** (360 кадров) — **вне гонки**, в таблице финиша «выбыл». В режимах на двоих с воскрешением
   корабль человека вместо этого восстанавливается через 8.2 с (RACE-23).

Как это выглядит у игрока [✓ наблюдение игрока, PAL, Time Trial; второй случай — корабль уничтожен принудительно на открытом месте: ✓ изменённая игра, PAL]:
- на последних делениях щита — надпись «shield energy critical»;
- **0 с** (щит 0): из корабля летят искры и обломки, он дымит и горит, ползёт с затухающей скоростью, управление не
  действует;
- **≈ +1.3 с**: корабль **разваливается на крупные куски** (крылья, корпус, фонарь разлетаются), по земле расходится
  голубое кольцо, затем большой огненный шар ~1 с;
- **≈ +2.6 с**: на месте корабля остаётся маленькая **капсула пилота** (`[escape pod]` в `SHIPS.INI`), сначала в огне;
  сверху плавно проявляется **дроид-спасатель** — крупный тёмный аппарат с надписью «RESCUE», зависает над трассой;
  капсула сама ползёт по трассе к нему;
- **≈ +5.5 с**: капсула исчезает (её забрали), дроид растворяется;
- **7.2 с**: в Time Trial — надпись «no medal awarded», затем выход в главное меню.
Моменты стадий в записях совпали с +1.2, +2.4, +4.4 и 7.2 с.

## SHIP-10. Убийство [✓]
Уничтожение засчитывается как **убийство** кораблю, чьё оружие его вызвало (если такой есть). Выбывание без
виновника (стены, лава и т.п.) никому не засчитывается. Убийства считаются отдельно в каждой гонке:
для каждого слота — множество уничтоженных им слотов.

## SHIP-11. Ввод [✓]
Ввод — набор действий плюс две аналоговые оси; ИИ заполняет **те же** поля (AI-1).

| действие | по умолчанию |
|---|---|
| руль влево / вправо (ось −255…255) | D-pad / стик |
| тангаж (ось −255…255) | D-pad / стик |
| газ | Cross |
| огонь (с силой нажатия) | Circle или R1 |
| аэротормоз левый / правый | L2 / R2 |
| взгляд назад (оружие стреляет назад) | L1 |
| сбросить / поглотить оружие | Square |
| смена вида | Triangle |
| пауза | Start |

Пауза, смена вида и сброс оружия срабатывают по **нажатию** (переходу «отпущено → нажато»), остальное — пока зажато. [код]
Мёртвые зоны стика и чувствительность — на усмотрение реализации.

## SHIP-12. Газ до старта [код]
Газ, нажатый до старта, отмечается в вводе отдельным признаком; он нужен для правила «заглох» (FLOW-6, FLOW-7).

## SHIP-13. Габариты корпуса [код]
При подготовке гонки у корабля появляется набор опорных точек корпуса (примерно ±3.0 по ширине, 0.4 по высоте,
от −4.0 до 8.06 по длине), видимо, для столкновений. Источник — модель корабля, а не файл параметров; точная геометрическая трактовка остаётся открытой (OQ-4).

## SHIP-14. Версия корабля и класс скорости [✓ два профиля; правило — код]
**Доля прокачки** корабля игрока: `p = floor(100 · Σ(уровень + 1) / Σ(число_уровней))` по шести группам SHIP-5,
где уровень группы — 0…(число_уровней − 1) или −1 («не куплено»), а **число уровней группы** — наибольшее n,
при котором хотя бы один ключ `<ГРУППА>_..._UPGn` этого корабля в `SHIPS.INI` не равен 0 (проверено для всех 16 кораблей;
у Feisar lead — 5, 3, 5, 5, 3, 5).

| p | версия модели (папка) | класс скорости |
|---|---|---|
| 0–24 | `VECTOR` | 1 |

- В Zone используется отдельный корабль `SHIPS/SECRET/`. [код]
- Модель корабля в меню (выбор корабля, ангар, «ship upgraded») **не отличается** от модели того же корабля на трассе:

## SHIP-15. Видимые повреждения корпуса [✓ наблюдения на 4 кораблях и запись 72 касаний; правило — код]
- Группы деталей модели (FMT-22) делятся на **6 участков** по ключевому слову в имени группы: нос — `NOSE`;
  двигатель — `ENGINE`; стабилизаторы — `STABILITY`; аэротормоза — `BRAKE`, `RUDDER`,
  `FLAP`; кабина — `COCKPIT`; фонарь — `CANOPY`. Этих слов достаточно: каждое имя группы во всех 33 кораблях
  содержит ровно одно из них (кроме `GUN_WEAPON`) [✓ файлы].
- Повреждение показывается **по каждой группе отдельно**. У каждой группы своя шкала повреждения 0…1; полный щит
  корабля поровну разделён между группами: удар, снявший `x` щита, добавляет группе `x / полный_щит × число_групп`
  (у корабля с 12 группами и щитом 71 касание стены −1 щита даёт группе +0.17). Удар достаётся **ближайшей к месту
  удара** группе, которая ещё не разбита полностью; излишек переходит к следующей ближайшей. Когда шкала группы
  доходит до **0.75**, вместо целой версии показывается повреждённая — при касаниях стены это **5-е касание** одной
  группы, 6-е добивает её до 1. [✓ видео, Time Trial Alca Vexus 2F: фонарь сменил вид в кадре касания, после вспышки
  удара] Если ближайшая неразбитая группа далеко от места удара (дальше ~10 единиц), удар по

  опустило его ниже 0.9 — щит обнулился, корабль уничтожен (SHIP-6). Всего снято 71 — весь щит [✓ запись]. В момент, когда группа становится повреждённой, игра выпускает **частицы-обломки** [код]; на видео

## SHIP-16. Уровни апгрейдов в гонке [код; ✓ запись гонок: 570 кораблей ИИ в 57 гонках]
Уровень группы: −1 — апгрейда нет, 0…(n − 1) — уровень 1…n, где n — число уровней группы у этого корабля (SHIP-14).
Перед каждой гонкой:
1. У всех кораблей все группы сбрасываются в −1.
2. **Демо-заезд** (заставка): так и остаётся — апгрейдов нет ни у кого.
3. **Одиночные режимы:** игрок получает свои купленные уровни из профиля. В челлендже уровни из профиля получают все 16
   пилотов.
4. Если событие разрешает подтягивать соперников (поле события, FMT-8; так в большинстве событий):
   - опорный уровень L = уровень группы TOPSPEED игрока;
   - в челлендже с заданным минимумом c ≥ 1 (FMT-8): все группы игрока = `min(c − 1, n − 1)`, и L — этот уровень;
   - в лиге `L = max(L, c)`;
   - каждый **другой** корабль в каждой группе получает `min(max(min(L, n − 1), уровень_игрока_в_группе), n − 1)` —
     то есть не ниже L и не ниже игрока, но не выше своего максимума.
5. **Режимы на двоих:** у всех кораблей каждая группа = `⌈(n − 1) · q / 100⌉`, где q = 0 / 34 / 67 / 100 по настройке
   «апгрейды» в меню режима на двоих.

Следствие: соперники всегда прокачаны не хуже игрока, а класс скорости (SHIP-14) у них тот же.
