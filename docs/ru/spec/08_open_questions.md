# 08. Открытые вопросы

Что неизвестно или известно только из кода. ID `OQ-N` стабильны: на них ссылаются правила. Когда вопрос закрыт,
строка остаётся с пометкой «закрыт → ID правила» и номером выпуска.

Колонка «как закрыть»: **наблюдение** — нужна запись игры (её может сделать и чистая команда, если хватает экрана);
**разбор** — работа грязной команды.
