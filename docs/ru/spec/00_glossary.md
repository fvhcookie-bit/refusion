# 00. Глоссарий

Термины спецификации. Английские слова — это ключи файлов данных или текст на экране игры.

## Время и симуляция
| термин | значение |
|---|---|
| **кадр** | шаг игровой логики, 20 мс игрового времени (GEN-1) |
| **подшаг** | половина кадра для физики, 0.01 с (PHY-1) |
| **часы гонки** | игровое время с момента подготовки гонки, без пауз (FLOW-4, FLOW-9) |
| **T** | время старта гонки по часам гонки, 4…7 с (FLOW-5) |
| **импульс за подшаг** | «сила» в формулах физики: прибавляется к скорости без умножения на время (PHY-10) |

## Трасса
| термин | значение |
|---|---|
| **трасса** | пара окружение + раскладка; **код трассы** `env·6 + circuit` (GEN-5) |
| **секция / подсекция** | участки геометрии трассы из файла `.TRK`; у секции есть «ворота» входа/выхода (FMT-3) |
| **доля круга** | число 0…1 для подсекции из файла `.LAP` (FMT-4) |
| **покрытие** | тип полигона трассы, определяется по имени материала (PHY-17) |
| **подтип покрытия** | звук/частицы/демпфирование: water, ice, rock, sand, stone, damage (PHY-18) |
| **триггер полигона** | особый полигон: ускоритель, оружейная площадка, переворот, мины (PHY-19) |
| **ускоритель** | триггер, разгоняющий корабль (PHY-11) |
| **оружейная площадка** | триггер, на котором корабль получает оружие (WPN-3) |
| **пит-лейн** | участок с ограничением скорости и подзарядкой щита (PHY-24) |
| **трамплин** | покрытие `air1/2/3`, подбрасывает корабль (PHY-20) |
| **линия старта** | покрытие `start`; её пересечение меняет счётчик кругов (RACE-3) |

## Корабль
| термин | значение |
|---|---|
| **команда** | одна из 8 (Feisar … Piranha), номер 0–7 (SHIP-1) |
| **пилот lead / second** | первый / второй пилот команды, номер в команде 0 / 1 (SHIP-1) |
| **слот** | номер корабля в таблицах результатов: `команда·2 + пилот` (SHIP-2) |
| **параметры корабля** | значения секции `SHIPS.INI` для слота (SHIP-3) |
| **живые параметры** | копия параметров на время гонки; её меняют апгрейды, урон, оружие, Zone (SHIP-4) |
| **апгрейд** | уровень 1–6 одной из 6 групп, заменяет базовый параметр (SHIP-5) |
| **щит** | запас прочности; 0 — корабль уничтожен (SHIP-6) |
| **узлы / повреждения узлов** | двигатель, нос, стабилизаторы, аэротормоза; 0…1 (SHIP-7) |
| **эффективная максимальная скорость** | `maxspeed` с учётом всех множителей в этом подшаге (PHY-4) |
| **ввод** | действия и оси геймпада; ИИ пишет те же поля (SHIP-11, AI-1) |
| **автопилот** | кораблём игрока управляет ИИ, геймпад игнорируется (FLOW-10) |
| **газ до старта / заглох** | газ, зажатый до старта, и штраф за него (FLOW-6) |
| **рывок** | мгновенный стартовый или турбо-разгон заданной силы (FLOW-6, WPN-6) |

## Гонка и результаты
| термин | значение |
|---|---|
| **событие** | описание одной гонки в `GAME.BNI`: тип, трасса, круги, пилоты, пороги медалей, оружие (FLOW-2, FMT-8) |
| **прогресс** | `круг − долг + доля_подсекции`; по нему сортируются места (RACE-2) |
| **долг** | число пересечений линии старта задом, ещё не компенсированных (RACE-2) |
| **текущая позиция** | место по прогрессу в этом кадре (RACE-5) |
| **таблица финиша** | итоговые места: заполняется в момент финиша или выбывания (FLOW-12) |
| **вне гонки** | корабль финишировал или выбыл; его результат зафиксирован |
| **уничтожен** | щит дошёл до 0; через 7.2 с корабль выбывает (SHIP-9) |
| **выбыл** | вне гонки без места: уничтожен, снят с лавы и т.п. |
| **убийство** | уничтожение соперника, вызванное оружием этого корабля (SHIP-10) |
| **поражён** | состояние после попадания ряда видов оружия (WPN-10) |
| **дроид-спасатель** | возвращает на трассу сорвавшийся корабль (PHY-22) |
| **резиновая нить** | ограничение скорости лидеров для подтягивания отстающих (RACE-7) |
| **perfect lap** | круг без касаний геометрии трассы (RACE-8) |
| **челлендж** | одиночное задание команды с медалями (RACE-13) |
| **медаль** | бронза / серебро / золото по трём порогам события; старшая включает младшие |
| **лига** | серия до 8 событий с очками (RACE-10) |
| **процент прохождения** | итоговая оценка профиля, 0–100 (RACE-17) |
| **доп. отметки** | дополнительные флаги профиля, входящие в процент; смысл не установлен (OQ) |
| **профиль** | сохранённый прогресс игрока (FMT-10, FMT-11) |
| **супероружие** | оружие, закреплённое за командой (WPN-2) |
| **открытое оружие** | оружие, разблокированное в профиле (FMT-10) |

## Терминология (RU ↔ EN)

| Русский | English | Примечание / не использовать |
|---|---|---|
| **щит** | shield | Множественное число — только для настройки игрока. Не: броня, энергия, здоровье. |
| **корпус** | hull | Тело корабля; его повреждения учитываются через узлы. Не: тело, шасси. |
| **узел** | component | Двигатель, нос, стабилизаторы, аэротормоза (SHIP-7). Не: компонент, деталь, блок. |
| **узел (дерева модели)** | model node | Элемент дерева модели (FMT-17, FMT-23). В английском для двух смыслов два слова, в русском одно. |
| **деталь / группа деталей** | part / part group | Часть модели корабля (SHIP-15, FMT-22); не узел корабля. |
| **доля круга** | lap progress | Число 0…1 для подсекции. Не: часть круга. |
| **прогресс** | progress | `круг − долг + доля_подсекции`, в кругах (RACE-2). |
| **текущая позиция / место** | current position / place | Текущая позиция пересчитывается каждый кадр; место — итоговое, в таблице финиша. |
| **аэротормоз** | airbrake | Не: воздушный тормоз. |
| **пит-лейн** | pit lane | Всегда участок целиком; не «пит», не «подзарядка» как место. |
| **подзарядка** | recharge | Подзарядка щита на пит-лейне (PHY-24). Не: пополнение. «Восстанавливается» — только в RACE-23. |
| **стартовая решётка / место на старте** | starting grid / grid position | Не: решётка старта. |
| **ускоритель** | booster | Триггер, разгоняющий корабль (PHY-11). Не: бустер, триггер ускорения, пэд-ускоритель. |
| **рывок** | burst | Мгновенный стартовый или турбо-разгон (FLOW-6, WPN-6); стартовый и турбо-рывок не различаются. Не: турбо-ускорение, стартовое ускорение, бустер. Серия выстрелов — «очередь», не «рывок». |
| **Turbo** | Turbo | Название оружия (как на экране). |
| **оружейная площадка** | weapon pad | Триггер (WPN-3); «площадка» — когда ясно из контекста. Не: пэд, подбор оружия (как триггер). |
| **подбор** | pickup | Действие получения оружия; не триггер. |
| **кулдаун площадки** | pad cooldown | Время после выдачи оружия, когда площадка ничего не выдаёт (WPN-3). Не: перезарядка. |
| **перезарядка** | reload | Собственный интервал между выстрелами оружия; не площадка. |
| **фонарь** | canopy | Две разные части модели корабля; не смешивать. |
| **кабина** | cockpit | См. фонарь. |
| **эффект попадания** | hit effect | Только заголовок WPN-10; состояние, которое он задаёт, — «поражён». |
| **поражён** | stricken | Состояние после эффекта попадания. Не: задет, попал. |
| **трамплин** | jump ramp | Без синонимов. |
| **уничтожен** | destroyed | Щит дошёл до 0 (SHIP-9). Не: убит, разбит. |
| **выбыл** | eliminated | Вне гонки без места. Не: вылетел. |
| **вне гонки** | out of the race | Финишировал или выбыл. |
| **убийство** | kill | Только смысл SHIP-10. Составляющая скорости «гасится», а не «убивается». |
| **Eliminator / Elimination** | Eliminator / Elimination | Название режима / типа челленджа, как на экранах игры. Не общее слово для выбывания корабля. |
| **покрытие** | surface | Тип полигона трассы (PHY-17); конкретное значение — «тип покрытия». |
| **подтип покрытия** | surface subtype | PHY-18. |
| **секция / подсекция** | section / subsection | Геометрия трассы из `.TRK`. |
| **отрезок** | segment | Линия от центра корабля в PHY-25; не подсекция. |
| **ворота** | gate | Ворота входа/выхода секции. |
| **кадр / подшаг** | frame / substep | Не: тик. |
| **импульс за подшаг** | per-substep impulse | «Сила» в формулах, в gfu. |
| **слот** | slot | `команда·2 + пилот` (SHIP-2). |
| **пилот** | pilot | Не: гонщик, водитель. |
| **корабль** | ship | Не: машина, судно. |
| **эффективная максимальная скорость** | effective maximum speed | `maxspeed` со всеми множителями (PHY-4). «Максимальная скорость» — базовый `maxspeed`; «высшая скорость» («top speed») — показатель на экране корабля. |
| **живые параметры** | live parameters | Копия параметров на время гонки. |
| **апгрейд** | upgrade | Не: тюнинг. |
| **профиль** | profile | Сохранённый прогресс целиком; «сохранение» — только файл на карте памяти. |
| **дроид-спасатель** | rescue droid | После первого упоминания — «дроид». |
| **точка возврата** | return point | Куда ставят сорвавшийся корабль (PHY-22). Не: респаун. |
| **воскрешение** | resurrection | Настройка и событие RACE-23. Не: возрождение, респаун. |
| **рестарт** | restart | Сброс гонки (FLOW-4). |
| **резиновая нить** | rubber band | Механизм. Пункт экрана настроек — «catch-up» («настройка catch-up»). |
| **perfect lap** | perfect lap | Надпись на экране, остаётся английской. |
| **наведение** | homing | Снаряд следует за целью; противоположность — «без наведения». Не: самонаведение. «Захват» — только захват цели. |
| **ввод** | input | Действия и оси геймпада. Внешнее управление — «управление извне». |
| **выстрел / заряд** | shot / charge | Заряд — единица запаса оружия. |
